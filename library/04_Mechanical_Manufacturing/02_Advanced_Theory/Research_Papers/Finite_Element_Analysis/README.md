### 1. Application of subject-specific adaptive mechanical loading for bone healing in a mouse tail vertebral defect

*File: `Application_of_subject_specific_adaptive_mechanical_loading_for_bone_h__W3124177967.pdf`*

**Brief:** Studies real-time finite element (rtFE) analysis from micro-CT to set subject-specific cyclic loads that promote bone healing without damaging the defected bone.

**Main notes:**

- rtFE estimates effective peak cyclic loads in a time-dependent, subject-specific way
- Tested in a cyclically loaded mouse caudal vertebral defect model
- Adaptive loading significantly improved healing over non-loaded controls with no vertebral fractures

### 2. Scientific Machine Learning Through Physics-Informed Neural Networks: Where we are and What's Next

*File: `Scientific_Machine_Learning_Through_Physics_Informed_Neural_Networks_W__W4288039037.pdf`*

**Brief:** Comprehensive review of physics-informed neural networks (PINNs), which encode PDEs into the network and fit data while reducing the PDE residual.

**Main notes:**

- PINNs are used for PDEs, fractional, integro-differential and stochastic PDEs
- Covers variants such as PCNN, hp-VPINN and CPINN
- Most research customizes activation functions, optimizers, architectures and loss functions
- In some contexts PINNs are more feasible than classical methods like FEM
