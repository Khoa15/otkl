### 2. Open Babel: An open chemical toolbox

*File: `Open_Babel_An_open_chemical_toolbox__W2169678694.pdf`*

**Brief:** Describes Open Babel, an open-source toolbox for converting chemical structure formats and doing cheminformatics.

**Main notes:**

- Version 2.3 interconverts over 110 formats
- Implements algorithms such as partial charge assignment, aromaticity detection, bond order perception and canonicalization
- Also offers conformer search, 2D depiction, filtering, batch conversion and substructure and similarity search
- Usable as a programming library
