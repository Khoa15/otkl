### 1. How to factor 2048 bit RSA integers in 8 hours using 20 million noisy qubits

*File: `How_to_factor_2048_bit_RSA_integers_in_8_hours_using_20_million_noisy__W2946582523.pdf`*

**Brief:** Reduces the estimated cost of factoring and discrete logarithms on a quantum computer by combining several prior techniques.

**Main notes:**

- Assumes superconducting grid, 1e-3 gate error, 1 microsecond surface code cycle, 10 microsecond reaction time
- Spacetime volume about a hundredfold lower than earlier estimates
- Abstract circuit: 3n + 0.002n lg n logical qubits
- Discusses cryptographic implications for RSA and finite-field DLP

### 2. Suppressing quantum errors by scaling a surface code logical qubit

*File: `Suppressing_quantum_errors_by_scaling_a_surface_code_logical_qubit__W4321610982.pdf`*

**Brief:** Google Quantum AI experiment testing whether increasing surface code size lowers logical error on a superconducting processor.

**Main notes:**

- Distance-5 logical qubit slightly beats distance-3 ensemble: 2.914% vs 3.028% error per cycle
- Distance-25 repetition code shows 1.7e-6 error floor from a high-energy event
- Error budgets extracted from an accurate model
