### 1. Accelerating materials property predictions using machine learning

*File: `Accelerating_materials_property_predictions_using_machine_learning__W2074616700.pdf`*

**Brief:** Shows that machine learning trained on quantum-mechanical computations can predict material properties quickly using chemical similarity.

**Main notes:**

- Demonstrated on one-dimensional chain systems
- Fingerprints based on chemo-structural information or electronic charge density
- Learns decision rules mapping easy attributes to properties

### 2. Quantum-chemical insights from deep tensor neural networks

*File: `Quantum_chemical_insights_from_deep_tensor_neural_networks__W2527189750.pdf`*

**Brief:** Develops deep tensor neural networks for molecular quantum-mechanical observables, combining many-body Hamiltonian concepts with deep learning.

**Main notes:**

- Size-extensive, uniformly accurate predictions (1 kcal/mol) for medium-sized molecules
- Gives atomic energies and local chemical potentials
- Classifies aromatic rings by stability
