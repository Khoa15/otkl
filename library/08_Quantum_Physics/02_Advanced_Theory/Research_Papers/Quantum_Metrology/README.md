### 2. Ultra-dense optical data transmission over standard fibre with a single chip source

*File: `Ultra_dense_optical_data_transmission_over_standard_fibre_with_a_singl__W3026186109.pdf`*

**Brief:** Uses soliton crystal micro-combs to demonstrate very high-rate optical data transmission over 75 km of standard fibre.

**Main notes:**

- Line rate 44.2 Tbit/s in the C-band
- Spectral efficiency 10.4 bit/s/Hz
- Comb spacing 48.9 GHz supports 64 QAM
- Single integrated chip source
