### 2. High-threshold and low-overhead fault-tolerant quantum memory

*File: `High_threshold_and_low_overhead_fault_tolerant_quantum_memory__W4393234688.pdf`*

**Brief:** IBM end-to-end fault-tolerant memory protocol based on low-density parity-check codes.

**Main notes:**

- Error threshold 0.7%, on par with the surface code
- Syndrome cycle uses n ancillas and a depth-8 CNOT circuit
- Needs degree-6 connectivity from two edge-disjoint planar subgraphs
- 12 logical qubits preserved for a long time with far fewer qubits than surface code
