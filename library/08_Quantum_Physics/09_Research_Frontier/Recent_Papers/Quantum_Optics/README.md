### 2. Tunable entangled photon-pair generation in a liquid crystal

*File: `Tunable_entangled_photon_pair_generation_in_a_liquid_crystal__W4399567319.pdf`*

**Brief:** First SPDC in a ferroelectric nematic liquid crystal.

**Main notes:**

- Efficiency comparable to the best nonlinear crystals
- Electric-field tunable broadband generation
- Rate and polarization changed with a few volts
- Twist-based reconfigurable quasi-phase matching
