### 1. Learning high-accuracy error decoding for quantum processors

*File: `Learning_high_accuracy_error_decoding_for_quantum_processors__W4404566610.pdf`*

**Brief:** Recurrent transformer neural network decoder for the surface code.

**Main notes:**

- Beats other decoders on Sycamore distance-3 and 5 data
- Advantage maintained on simulated data up to distance 11 with cross-talk and leakage
- Uses soft readouts and leakage information
- Trained on approximate synthetic data then adapted

### 2. Sparse Blossom: correcting a million errors per core second with minimum-weight matching

*File: `Sparse_Blossom_correcting_a_million_errors_per_core_second_with_minimu__W4406617380.pdf`*

**Brief:** Fast minimum-weight perfect matching decoder for quantum error correcting codes.

**Main notes:**

- Avoids all-to-all Dijkstra searches
- Under 1 microsecond per round for distance-17 surface code at 0.1% noise on one core
- Open source in PyMatching v2
