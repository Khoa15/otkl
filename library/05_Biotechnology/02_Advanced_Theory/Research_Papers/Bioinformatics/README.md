### 1. Highly accurate protein structure prediction with AlphaFold

*File: `Highly_accurate_protein_structure_prediction_with_AlphaFold__W3177828909.pdf`*

**Brief:** Describes AlphaFold, a neural network system that predicts protein 3D structure from sequence. It targets the gap between about 100,000 solved structures and billions of known sequences.

**Main notes:**

- Computational structure prediction is needed because experimental determination takes months to years
- Paper is a Nature article from 2021 by a DeepMind-led team
- Extracted text covers only the introduction of the approach

### 2. WGCNA: an R package for weighted correlation network analysis

*File: `WGCNA_an_R_package_for_weighted_correlation_network_analysis__W1966327575.pdf`*

**Brief:** Software paper presenting an R package for weighted correlation network analysis, used to describe correlation patterns among genes across samples.

**Main notes:**

- Finds modules (clusters) of highly correlated genes
- Summarizes modules by module eigengene or intramodular hub gene
- Relates modules to each other and to external sample traits
- Supports network-based screening for candidate biomarkers or therapeutic targets
