### 1. Avogadro: an advanced semantic chemical editor, visualization, and analysis platform

*File: `Avogadro_an_advanced_semantic_chemical_editor_visualization_and_analys__W2028046413.pdf`*

**Brief:** Software paper describing Avogadro, a cross-platform molecular editor and visualizer with a library and API for 3D visualization.

**Main notes:**

- Used for building structures, formatting input files and analyzing output of computational chemistry packages
- Plugin architecture extensible in C++ or Python
- Uses CML as native file format to improve semantic access to chemical data

### 2. GSVA: gene set variation analysis for microarray and RNA-Seq data

*File: `GSVA_gene_set_variation_analysis_for_microarray_and_RNA_Seq_data__W2159707944.pdf`*

**Brief:** Introduces GSVA, a gene set enrichment method that estimates pathway activity variation across a sample population in an unsupervised way.

**Main notes:**

- Compared with state-of-the-art sample-wise enrichment methods, showing robustness
- Gives more power to detect subtle pathway activity changes
- Examples in differential pathway activity and survival analysis
- Works with both microarray and RNA-seq data
