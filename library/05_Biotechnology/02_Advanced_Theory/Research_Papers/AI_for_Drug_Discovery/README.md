### 1. DeepConv-DTI: Prediction of drug-target interactions via deep learning with convolution on protein sequences

*File: `DeepConv_DTI_Prediction_of_drug_target_interactions_via_deep_learning__W2899788782.pdf`*

**Brief:** Addresses drug-target interaction (DTI) prediction, where conventional protein descriptors are not informative enough. Proposes a CNN applied to raw protein sequences to capture local residue patterns.

**Main notes:**

- Convolution is run over amino acid subsequences of various lengths
- Trained on large-scale DTI data and tested on an independent unseen dataset
- Reported to outperform earlier protein-descriptor-based models

### 2. Optimization of Molecules via Deep Reinforcement Learning

*File: `Optimization_of_Molecules_via_Deep_Reinforcement_Learning__W2962764565.pdf`*

**Brief:** Presents MolDQN, a framework for molecule optimization that combines chemistry knowledge with reinforcement learning. It modifies molecules directly so every result is chemically valid.

**Main notes:**

- Uses double Q-learning and randomized value functions
- Needs no pre-training on any dataset, avoiding dataset bias
- Comparable or better than other published methods on benchmark tasks
- Extended to multi-objective optimization (drug-likeness while keeping similarity to the original molecule)
