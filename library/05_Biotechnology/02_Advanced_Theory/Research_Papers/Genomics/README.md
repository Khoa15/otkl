### 1. HTSeq - A Python framework to work with high-throughput sequencing data

*File: `HTSeq_a_Python_framework_to_work_with_high_throughput_sequencing_data__W2134526812.pdf`*

**Brief:** Presents HTSeq, a Python library that speeds up writing custom scripts for high-throughput sequencing analysis when standard workflows do not fit.

**Main notes:**

- Parsers for common HTS data formats
- Classes for genomic coordinates, sequences, reads, alignments, gene models and variant calls
- Includes htseq-count, which counts read overlap with genes for RNA-seq differential expression
- Open source under GNU GPL
