### 1. Differential analyses for RNA-seq: transcript-level estimates improve gene-level inferences

*File: `Differential_analyses_for_RNA_seq_transcript_level_estimates_improve_g__W2197124664.pdf`*

**Brief:** Method article showing that using transcript-level abundance estimates improves gene-level differential expression analysis of RNA-seq data.

**Main notes:**

- Compares quantification approaches from read counting to transcript abundance estimation
- Claim: gene-level inferences improve with transcript-level estimates
- F1000Research, version 2, peer reviewed

### 2. MAST: a flexible statistical framework for assessing transcriptional changes and characterizing heterogeneity in single-

*File: `MAST_a_flexible_statistical_framework_for_assessing_transcriptional_ch__W2190545194.pdf`*

**Brief:** Proposes a two-part generalized linear model for single-cell RNA-seq data, which show dropout and bimodal expression.

**Main notes:**

- Parameterizes both detection and expression level
- Adjusts for cellular detection rate as nuisance variation
- Provides gene set enrichment analysis tailored to single-cell data
- Software available on GitHub
