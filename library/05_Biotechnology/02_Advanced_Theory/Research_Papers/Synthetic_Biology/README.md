### 1. Inferring Regulatory Networks from Expression Data Using Tree-Based Methods

*File: `Inferring_Regulatory_Networks_from_Expression_Data_Using_Tree_Based_Me__W2076513103.pdf`*

**Brief:** Presents GENIE3, an algorithm for inferring gene regulatory networks from expression data; best performer in the DREAM4 In Silico Multifactorial challenge.

**Main notes:**

- Splits network prediction among p genes into p regression problems
- Each target gene predicted from all others using Random Forests or Extra-Trees
- Input gene importance indicates a putative regulatory link

### 2. Recurrent Neural Networks for Multivariate Time Series with Missing Values

*File: `Recurrent_Neural_Networks_for_Multivariate_Time_Series_with_Missing_Va__W2964010366.pdf`*

**Brief:** Develops GRU-D, a GRU-based deep model that uses missing-value patterns in multivariate time series, since missingness is often informative about labels.

**Main notes:**

- Uses two representations of missingness: masking and time interval
- Captures long-term temporal dependencies and exploits missing patterns
- Tested on MIMIC-III, PhysioNet and synthetic data with state-of-the-art results
