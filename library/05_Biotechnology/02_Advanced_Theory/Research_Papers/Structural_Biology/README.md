### 1. ColabFold: making protein folding accessible to all

*File: `ColabFold_making_protein_folding_accessible_to_all__W4281790889.pdf`*

**Brief:** Brief communication on ColabFold, which speeds protein structure and complex prediction by combining MMseqs2 homology search with AlphaFold2 or RoseTTAFold.

**Main notes:**

- 40-60-fold faster search
- Close to 1,000 structure predictions per day on one GPU server
- Optimized model utilization

### 2. I-TASSER server for protein 3D structure prediction

*File: `I_TASSER_server_for_protein_3D_structure_prediction__W2155201844.pdf`*

**Brief:** Describes the online I-TASSER server for predicting protein 3D structures from amino acid sequences, ranked best server method in CASP7.

**Main notes:**

- Introduces C-score, based on clustering density and threading template consensus, to estimate prediction accuracy
- Generated predictions for thousands of requests from over 35 countries
- Includes a large-scale benchmark test
