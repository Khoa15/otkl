### 1. Enrichr: interactive and collaborative HTML5 gene list enrichment analysis tool

*File: `Enrichr_interactive_and_collaborative_HTML5_gene_list_enrichment_analy__W2070050178.pdf`*

**Brief:** Software paper presenting Enrichr, a web-based and mobile tool for gene-set enrichment analysis of lists of differentially expressed genes or proteins against gene-set libraries.

**Main notes:**

- Takes gene or protein lists from system-wide profiling
- Computes enrichment against libraries built from prior knowledge
- Interactive, collaborative HTML5 interface

### 2. MZmine 2: Modular framework for processing, visualizing, and analyzing mass spectrometry-based molecular profile data

*File: `MZmine_2_Modular_framework_for_processing_visualizing_and_analyzing_ma__W1989299822.pdf`*

**Brief:** Presents MZmine 2, an open-source toolbox for processing mass spectrometry data used in metabolomics and proteomics. Its design strictly separates core functionality from data-processing modules.

**Main notes:**

- Open-source data processing toolbox for MS-based profiling
- Strict separation of core functionality and processing modules
- Used for differential and quantitative profiling and biomarker discovery
