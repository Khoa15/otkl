### 1. FPGA-based Implementation of a Resource-Efficient UNET Model for Brain Tumour Segmentation

*File: `FPGA_based_Implementation_of_a_Resource_Efficient_UNET_Model_for_Brain__W4391545934.pdf`*

**Brief:** Implements an optimized UNET with reduced depth and fewer filters on FPGA for brain tumour segmentation on the BraTS dataset, using HLS4ML.

**Main notes:**

- Reduced depth and fewer filters for FPGA efficiency
- Uses High-Level Synthesis for Machine Learning (HLS4ML)
- Evaluated on the BraTS dataset

### 2. Project and Implementation of a Quantum Logic Gate Emulator on FPGA Using a Model-Based Design Approach

*File: `Project_and_Implementation_of_a_Quantum_Logic_Gate_Emulator_on_FPGA_Us__W4392745519.pdf`*

**Brief:** Describes step by step how to design a quantum gate emulator on FPGA using a model-based design approach instead of low-level HDL.

**Main notes:**

- Emulators test quantum algorithms before real hardware
- Low-level HDL design is complex and time-consuming
- Higher-level model-based approach simplifies the work
