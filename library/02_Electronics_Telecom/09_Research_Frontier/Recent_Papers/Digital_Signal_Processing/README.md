### 1. Broadband angular spectrum differentiation using dielectric metasurfaces

*File: `Broadband_angular_spectrum_differentiation_using_dielectric_metasurfac__W4392886376.pdf`*

**Brief:** Demonstrates analog optical processing that performs mathematical operations (differentiation) directly on the angular spectrum of an image using dielectric metasurfaces.

**Main notes:**

- Analog optical processing is fast and energy-efficient versus digital
- Fourier optics enables operations such as edge detection
- Targets operations acting on the angular spectrum
