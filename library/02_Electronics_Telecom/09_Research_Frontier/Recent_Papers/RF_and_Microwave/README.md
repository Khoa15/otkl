### 1. A system-on-chip microwave photonic processor solves dynamic RF interference in real time with picosecond latency

*File: `A_system_on_chip_microwave_photonic_processor_solves_dynamic_RF_interf__W4390725418.pdf`*

**Brief:** Presents a microwave photonic processor on a chip that cancels dynamic RF interference with picosecond latency, motivated by conflicts such as radar altimeters and 5G.

**Main notes:**

- RF interference is growing as wireless advances
- Conventional DSP has high latency for time-varying mixing
- Photonic processor responds in real time
