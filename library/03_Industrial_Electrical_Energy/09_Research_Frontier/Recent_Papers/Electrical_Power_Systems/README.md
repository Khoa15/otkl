### 1. Development of the CMS detector for the CERN LHC Run 3

*File: `Development_of_the_CMS_detector_for_the_CERN_LHC_Run_3__W4389901936.pdf`*

**Brief:** Describes the CMS particle detector as configured for LHC Run 3 (from 2022). It is a high-energy physics paper, not a power systems one.

**Main notes:**

- Entire silicon pixel tracker replaced and a new solenoid powering system installed
- Upgraded hadron calorimeter and muon electronics, with new muon stations including a GEM detector
- New hybrid CPU/GPU farm for the high-level trigger
