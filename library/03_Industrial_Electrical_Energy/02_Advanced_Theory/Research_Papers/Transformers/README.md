### 1. Deep Learning Enabled Semantic Communication Systems

*File: `Deep_Learning_Enabled_Semantic_Communication_Systems__W3036851434.pdf`*

**Brief:** Proposes DeepSC, a Transformer-based semantic communication system for text transmission that recovers sentence meaning instead of bits or symbols. It concerns the neural-network Transformer, not electrical transformers.

**Main notes:**

- Aims to maximize capacity and minimize semantic errors
- Transfer learning makes DeepSC applicable to different communication environments and speeds training
- Published in IEEE Transactions on Signal Processing, 2021

### 2. Mamba: Linear-Time Sequence Modeling with Selective State Spaces

*File: `Mamba_Linear_Time_Sequence_Modeling_with_Selective_State_Spaces__W4389326242.pdf`*

**Brief:** Introduces Mamba, a sequence model using selective state space models as a subquadratic alternative to Transformer attention. It is a machine learning paper, not about electrical transformers.

**Main notes:**

- Key weakness of prior SSMs is lack of content-based reasoning
- Making SSM parameters input-dependent lets the model selectively propagate or forget information
- Hardware-aware parallel algorithm in recurrent mode replaces efficient convolutions
