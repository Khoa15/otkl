### 1. Inertial microfluidic mixer for biological CubeSat missions

*File: `Inertial_microfluidic_mixer_for_biological_CubeSat_missions__W4403051628.pdf`*

**Brief:** Presents a microfluidic mixer system for biological research aboard CubeSats, using MEMS tools.

**Main notes:**

- Aims for low complexity suited to failure-free, remotely controlled operation
- Inertial microfluidic approach for mixing
