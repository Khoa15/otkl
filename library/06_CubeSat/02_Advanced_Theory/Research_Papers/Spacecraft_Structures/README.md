*File: `High_Gain_Compact_Circularly_Polarized_X_Band_Superstrate_Antenna_for__W3157971931.pdf`*

**Brief:** Presents a high-gain circularly polarized X-band antenna using a partially reflecting surface, for CubeSat communications.

**Main notes:**

- Return loss bandwidth above 10 dB of 20% (8-9.8 GHz); CP over 8.35-8.95 GHz
- Compact size 62 x 62 x 22.2 mm and 29.7 g
- Parasitic element size in the PRS was analysed to optimise pattern
