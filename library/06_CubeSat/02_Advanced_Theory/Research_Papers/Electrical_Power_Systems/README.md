**Main notes:**

- Must handle highly variable power needs and protect the satellite from subsystem malfunctions
- Built only from commercial off-the-shelf components
- Paper covers design and pre-flight testing

### 3. Multiport Converter for CubeSat

*File: `Multiport_Converter_for_CubeSat__W4283828531.pdf`*

**Brief:** Addresses the challenge of maximising solar energy harvesting while miniaturising DC-DC converters on LEO CubeSats. It proposes a multiport converter that needs only one inductor.

**Main notes:**

- Conventional EPS uses several separate DC-DC converters, each with its own inductor
- Proposed topology uses series-connected half-bridge modules in parallel with PV panels feeding a boost converter to the battery
- A prototype following 1U CubeSat standards verifies performance in several scenarios

### 4. Optimized Load-Scheduling Algorithm for CubeSat's Electric Power System Management Considering Communication Link

*File: `Optimized_Load_Scheduling_Algorithm_for_CubeSat_s_Electric_Power_Syste__W4382725582.pdf`*

**Brief:** Proposes an optimisation approach to schedule CubeSat loads so that demand, generation and storage are coordinated while the communication link's quality of service is kept.

**Main notes:**

- Loads are divided into four priority types: time-modulated, magnitude-modulated, both, and fixed
- Optimisation problem includes data rate and bit-error rate in the cost function with energy and power constraints
- Multiple cases are investigated
