### 1. Development of an Autonomous Redundant Attitude Determination System for CubeSats

*File: `Development_of_an_Autonomous_Redundant_Attitude_Determination_System_f__W3046783908.pdf`*

**Brief:** Describes the SDATF, a CubeSat attitude determination system with triple redundancy and fault-tolerance tools.

**Main notes:**

- Uses the QUEST method with quaternions
- Planned in-flight test as an experiment payload on NanosatC-BR2 (INPE, Brazil)
- Does not control the CubeSat's attitude strategy

### 2. On Board Computer Module for Cubesat Compatible with QB50

*File: `On_Board_Computer_Module_for_Cubesat_Compatible_with_QB50__W2903298198.pdf`*

**Brief:** Presents hardware design and implementation of an OBC-OBDH subsystem meeting QB50 requirements.

**Main notes:**

- FreeRTOS real-time operating system implemented
- Simple example using all modules prepared
- Justified academically by the QB50 project
