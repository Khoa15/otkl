### 2. Near Real-Time Wildfire progression Monitoring with Sentinel-1 SAR Time Series and Deep Learning

*File: `Near_Real_Time_Wildfire_Progression_Monitoring_with_Sentinel_1_SAR_Tim__W3003452346.pdf`*

**Brief:** Shows how Sentinel-1 SAR, which sees through cloud and smoke day and night, can support near real-time monitoring of wildfire progression. A CNN-based framework detects burnt areas from each new SAR image.

**Main notes:**

- CNN uses every new SAR image together with the pre-fire SAR time series to capture temporal backscatter changes
- Demonstrated on three large wildfires, including the 2017 Elephant Hill and 2018 Camp fires
- Results show SAR backscatter can detect fires and track their progression
