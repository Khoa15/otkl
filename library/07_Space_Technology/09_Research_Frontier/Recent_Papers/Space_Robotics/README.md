### 1. DexVLA: Vision-Language Model with Plug-In Diffusion Expert for General Robot Control

*File: `DexVLA_Vision_Language_Model_with_Plug_In_Diffusion_Expert_for_General__W4407385957.pdf`*

**Brief:** Proposes DexVLA, a vision-language-action framework for generalized dexterous, long-horizon manipulation across embodiments.

**Main notes:**

- Argues action representation is a bottleneck in current VLAs.
- Uses a diffusion-based action expert scaled to one billion parameters.
- Designed for cross-embodiment learning.

### 2. Executable Code Actions Elicit Better LLM Agents

*File: `Executable_Code_Actions_Elicit_Better_LLM_Agents__W4391555701.pdf`*

**Brief:** Proposes CodeAct, using executable Python code as a unified action space for LLM agents.

**Main notes:**

- Integrated with a Python interpreter that can revise actions across turns.
- Evaluated on 17 LLMs on API-Bank and a new benchmark.
- Up to 20% higher success rate than alternatives.
