- Evaluated on almost 40 tasks.
- Includes remote-sensing and segmentation tasks.

### 2. RemoteCLIP: A Vision Language Foundation Model for Remote Sensing

*File: `RemoteCLIP_A_Vision_Language_Foundation_Model_for_Remote_Sensing__W4394938913.pdf`*

**Brief:** Proposes the first vision-language foundation model for remote sensing, supporting retrieval and zero-shot use.

**Main notes:**

- Prior SSL and MIM models learn low-level features and need annotations.
- Box-to-Caption and Mask-to-Box conversions unify heterogeneous annotations.
- Adding UAV imagery yields a pretraining set 12x larger.
