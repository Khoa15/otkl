*File: `Octo_An_Open_Source_Generalist_Robot_Policy__W4398192846.pdf`*

**Brief:** Introduces Octo, an open-source transformer-based generalist policy for robotic manipulation.

**Main notes:**

- Supports flexible task definitions (goal image or language), observations and action spaces.
- Can be quickly finetuned to new observation and action spaces.
