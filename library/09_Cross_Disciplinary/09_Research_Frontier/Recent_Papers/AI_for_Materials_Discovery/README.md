### 1. A framework to evaluate machine learning crystal stability predictions

*File: `A_framework_to_evaluate_machine_learning_crystal_stability_predictions__W4411543224.pdf`*

**Brief:** Presents Matbench Discovery, an evaluation framework for machine learning energy models used as pre-filters in high-throughput searches for stable inorganic crystals. It addresses the need for community-agreed benchmarks and the gap between formation energy and thermodynamic stability, and between retrospective and prospective benchmarking.

**Main notes:**

- Publishes a Python package for future model submissions and an online leaderboard with adaptive user-defined metric weighting.
- Initial release compares random forests, graph neural networks and other methodologies.
- Published in Nature Machine Intelligence, June 2025.

### 2. AI-driven materials design: a mini-review

*File: `Artificial_intelligence_driven_approaches_for_materials_design_and_dis__W7118011688.pdf`*

**Brief:** A mini-review of computational and AI-enhanced approaches to materials design, which traditionally relies on trial and error. It highlights inverse design, which targets specific property requirements.

**Main notes:**

- Summarizes key computational advances in materials design over past decades.
- Notes AI has greatly accelerated materials design.
- Inverse design is highlighted as especially promising.
