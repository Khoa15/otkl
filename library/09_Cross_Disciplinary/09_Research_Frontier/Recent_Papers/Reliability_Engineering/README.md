### 2. Prompt engineering in consistency and reliability with the evidence-based guideline for LLMs

*File: `Prompt_engineering_in_consistency_and_reliability_with_the_evidence_ba__W4391971084.pdf`*

**Brief:** Tests how prompt style affects the consistency and reliability of LLM answers against AAOS osteoarthritis evidence-based guidelines.

**Main notes:**

- Different prompts and LLMs were asked guideline questions, each five times.
- gpt-4-Web with ROT prompting had the highest overall consistency (62.9%).
- Consistency for strong recommendations was 77.5% for that setup.
