### 1. Feature selection strategies: a comparative analysis of SHAP-value and importance-based methods

*File: `Feature_selection_strategies_a_comparative_analysis_of_SHAP_value_and__W4393182100.pdf`*

**Brief:** Compares feature selection using SHAP values with selection using a model's built-in feature importance, applied to high-dimensional credit card fraud data.

**Main notes:**

- Both methods rank features and select the most significant ones.
- Classification models are built to evaluate the effectiveness of each technique.
- Motivated by data quality as a key challenge in finance and machine learning.

### 2. YOLO v11: An Overview of the Key Architectural Enhancements

*File: `YOLOv11_An_Overview_of_the_Key_Architectural_Enhancements__W4404303854.pdf`*

**Brief:** An architectural analysis of YOLOv11, the latest in the YOLO object detection series, and its capabilities across vision tasks.

**Main notes:**

- Examines the C3k2 block, SPPF and C2PSA components for improved feature extraction.
- Supports object detection, instance segmentation, pose estimation and oriented object detection.
- Reviews mAP and efficiency gains and the parameter-versus-accuracy trade-off.
- Covers model sizes from nano to extra-large, from edge devices to HPC.
