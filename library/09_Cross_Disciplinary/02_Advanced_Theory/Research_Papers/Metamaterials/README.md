### 2. Three-dimensional optical holography using a plasmonic metasurface

*File: `Three_dimensional_optical_holography_using_a_plasmonic_metasurface__W2089762744.pdf`*

**Brief:** Demonstrates 3D holography with metasurfaces built from subwavelength metallic nanorods with spatially varying orientations. It exploits the phase discontinuity that occurs when circularly polarized light reverses helicity.

**Main notes:**

- Phase in each unit cell is continuously controlled by nanorod orientation.
- Gives high-resolution on-axis 3D holograms with a wide field of view.
- Eliminates the unwanted multiple diffraction orders usually seen in holography.
